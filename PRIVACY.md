# NuevAI privacy notice

NuevAI is a school information assistant for The Nueva School community, built and run as a student/staff project. It is not an official school service.

## What the Google connection does
The account nuevai.updates@gmail.com gives NuevAI read-only access (Google Drive and Google Sheets read-only scopes) to the files and emails that people choose to share with that address. NuevAI reads only those items, extracts schedule and school-information text, and stores that text so the assistant can answer questions.

## What is stored
- Cleaned text and schedule details from shared Sheets, Docs and forwarded emails (for example game schedules or practice announcements).
- Basic bookkeeping about each item (an identifier hash, last-modified time, and whether it was processed).
- Not stored: student rosters, student names or contact details (such items are skipped), passwords, personal phone numbers, or the full addresses of senders.

## What is not done
- No data is sold or shared with advertisers.
- No data is used to build user profiles.
- Access tokens are kept as encrypted repository secrets and are never printed or published.

## Your choices
Stop sharing a file with the address, or remove it from Google Drive, and it is no longer read. To request removal of something already stored, contact nuevai.updates@gmail.com.
